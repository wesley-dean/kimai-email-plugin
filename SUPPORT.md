# Getting Support

## Usage and Defect Reports

For questions, installation problems, or reproducible defects, open an issue in
this repository:

https://github.com/wesley-dean/kimai-email-plugin/issues

Before opening an issue, please include enough environment information to make
the problem reproducible:

- Kimai version;
- PHP version;
- plugin release or commit;
- installation method;
- whether Kimai runs directly or in a container;
- the relevant error message or log excerpt with sensitive values removed; and
- the steps needed to reproduce the behavior.

The maintained compatibility baseline is documented in
[doc/compatibility.md](doc/compatibility.md).

## Security Issues

Do not report suspected vulnerabilities in a public issue.

Use the private reporting path in [SECURITY.md](SECURITY.md).

## Scope

The current maintained release supports the manual invoice-email workflow
documented in [README.md](README.md).

Automatic sending, retries, invoice status changes, delivery receipts, and
additional-recipient behavior are outside the current maintained scope.  A
support request does not implicitly expand that contract.
